# Паспорт стиля — «Деловой стандарт» (по фото экрана, 4 слайда)

Цвета сняты с фотографий монитора: камера затемняет и приглушает цвета, поэтому оттенок (hue) взят из замеров,
а насыщенность и яркость приведены к экранному виду. **Точные HEX-коды нужно сверить с корпоративным шаблоном .potx/брендбуком.**

| Роль | HEX | Замер с фото | Где применяется |
|---|---|---|---|
| Зелёный (заголовок, 1-я строка) | `3F8A3A` | `557A4C` | первая строка заголовка, жирные ключевые слова |
| Зелёный акцент | `4F9D46` | `688E57` / `6A965E` | кнопка-«пилюля», вкладка с логотипом, ряд 2026 |
| Синий (заголовок, 2-я строка) | `2F5FA6` | `44638D` | вторая строка заголовка, жирные слова в списках |
| Тёмно-синий | `1D3F7A` | `3C445B` | левые полосы фона, контуры схем |
| Лайм | `9BC53D` | `84934F` | светлые полосы фона, цементное кольцо на схемах |
| Янтарь | `E0A93B` | `9F895A` | точка индикатора, верх вертикальной шкалы |
| Красный (из 3D-мишени) | `C9453F` | `995E59` | недоподъём цемента, наихудшие операции |
| Текст | `34373D` | `3C3B3F` | основной текст |
| Фон карточки | `F4F7FA` | `D6D8D3` (через экран) | большая «стеклянная» карточка |

## Конструкция слайда
1. Фон: наклонные полосы синий → бирюзовый → зелёный → лайм по верхнему и левому краю, справа уходят в светлое холодное поле.
2. Большая скруглённая «стеклянная» карточка с двойным краем (эффект glassmorphism) занимает около 90 % слайда.
3. Слева вверху зелёная вкладка со скруглённым низом и белой иконкой-логотипом.
4. Надзаголовок — название раздела капсом, серый, ~11 пт, с разрядкой.
5. Заголовок в две строки, шрифт широкий и жирный: 1-я строка зелёная, 2-я синяя.
6. Справа вверху индикатор: янтарная точка, зелёное короткое тире, синее длинное тире.
7. Внутренняя светлая карточка для контента.
8. Справа внизу «пилюля» с кружком-номером. В оригинале это «Следующий эпизод через (1)», здесь — ссылка на лист расчёта и номер слайда.
9. Списки: вертикальная градиентная шкала (янтарь → зелёный → синий), тонкие выноски, ключевое слово жирным синим, остальное обычным шрифтом.
10. Иконки: белые контурные в зелёных скруглённых квадратах.
11. Титульный слайд: 3D-иллюстрации слева, заголовок по центру, зелёная кнопка-«пилюля»; справа — светлые плитки
    с 3D-иконками и маленькой зелёной точкой в левом верхнем углу; вверху карточки — светлая полоса с индикатором.
12. Нижняя линия — ступенчатая (5 сегментов: тёмно-синий → синий → зелёный → зелёный → лайм), не плавный градиент.
13. На фоне внизу по центру — полупрозрачная светлая панель, частично уходящая под карточку.
14. Переход между слайдами — «Сдвиг» (push): полосы фона неподвижны, карточка уезжает влево, новая приходит справа;
    кнопка появляется с анимацией. В сборке переход «Сдвиг» дописывается во все слайды (`addPushTransitions`).

## Шрифты
По фото это широкий геометрический гротеск: жирный для заголовков, обычный для текста.
Точное название по фото не определить. Ближайший свободный аналог с кириллицей — **Montserrat**
(ExtraBold для заголовков, Regular/Medium для текста), он и заложен в `style.js` (объект `F`).
Если в компании свой шрифт, достаточно заменить три имени в `F`.
Montserrat (Google Fonts, лицензия OFL) должен быть установлен на ПК, где открывается презентация.
Без него PowerPoint подставит другой шрифт.

## Правила для диаграмм (аналитическая часть)
- 2025 — серо-синий `8FA6C4` и подпись «опубликованный агрегат»: без медианы и распределения, если нет построчных данных.
- 2026 — зелёный акцент `4F9D46`.
- «н/д» — серая ячейка `E4E8ED`, значения не восстанавливаются.
- Пороги 0,80 и 0,90 показываются оба, пока утверждённый критерий не подтверждён.
- Цветовая шкала тепловой карты — не критерий «хорошо/плохо».
- Каждый слайд несёт ссылку на лист и строки файла расчётов.

## Сборка
```
cd build && npm install && python3 make_bg.py assets/bg.jpg && node build_style_sample.js
```
Результат: `output/style_sample.pptx`. На слайдах 2–3 — условные демо-данные только для показа оформления.
