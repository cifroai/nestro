# Оценка кандидата — Telegram Mini App

Приложение для коллективной оценки кандидата по итогам собеседования.
Ссылку размещаете в корпоративном мессенджере **Express** — любой, кто по ней перейдёт,
открывает приложение в Telegram, ставит балл, при желании пишет комментарий и нажимает
**Принять**, **Отклонить** или **В резерв**. После голосования сразу видны общие результаты.

## Как это работает

1. Вы создаёте кандидата и получаете ссылку вида `https://t.me/<бот>/<app>?startapp=<id>`.
2. Публикуете ссылку в Express.
3. Участник нажимает на ссылку → открывается Telegram → Mini App с карточкой кандидата.
4. Участник выбирает балл (по умолчанию шкала 1–10) и нажимает одно из решений.
5. Открывается экран **«Общая оценка»**:
   - средний балл и число оценок;
   - распределение решений (Принять / Отклонить / В резерв) и решение большинства;
   - список участников с их баллом, решением и комментарием.

Особенности:

- Один человек — один голос: личность берётся из подписанных данных Telegram (подделать нельзя),
  повторное голосование заменяет прежнюю оценку («Изменить мою оценку»).
- Результаты видны только тем, кто уже проголосовал, чтобы не влиять на независимость оценки.
- Для каждого кандидата — отдельная ссылка, результаты не смешиваются.

## Запуск

Нужен Node.js 18+ (внешних зависимостей нет) и сервер с HTTPS-адресом — Telegram открывает
Mini App только по `https://`.

### 1. Создайте бота и Mini App в @BotFather

1. `/newbot` → получите **токен** и **username** бота.
2. `/newapp` → выберите бота, укажите название, описание, картинку 640×360,
   **URL** вашего сервера (например `https://rate.example.ru/`) и **short name** (например `rate`).

### 2. Запустите сервер

```bash
cd interview-rating
export BOT_TOKEN=123456:ABC...        # токен бота
export BOT_USERNAME=my_interview_bot  # username бота
export APP_SHORT_NAME=rate            # short name Mini App
npm start
```

Или в Docker:

```bash
docker build -t interview-rating .
docker run -d -p 3000:3000 -e BOT_TOKEN=... -v $(pwd)/data:/app/data interview-rating
```

Сервер слушает порт 3000; поставьте перед ним nginx/Caddy с HTTPS или опубликуйте
на любом хостинге (Render, Railway, VPS и т. п.).

### 3. Добавьте кандидата и получите ссылку

```bash
npm run candidates -- add "Иванов Иван Иванович" "Ведущий аналитик"
# Кандидат добавлен: Иванов Иван Иванович (id: 04uLblD5)
# Ссылка для Express: https://t.me/my_interview_bot/rate?startapp=04uLblD5
```

Эту ссылку и размещаете в Express.

Другие команды:

```bash
npm run candidates -- list            # все кандидаты и их ссылки
npm run candidates -- results <id>    # итоги в консоли
npm run candidates -- remove <id>     # удалить кандидата
```

## Настройки (переменные окружения)

| Переменная       | По умолчанию       | Назначение                                      |
|------------------|--------------------|-------------------------------------------------|
| `BOT_TOKEN`      | —                  | Токен бота, обязателен (проверка подписи)       |
| `BOT_USERNAME`   | —                  | Username бота — для формирования ссылки         |
| `APP_SHORT_NAME` | —                  | Short name Mini App — для формирования ссылки   |
| `PORT`           | `3000`             | Порт HTTP-сервера                               |
| `SCORE_MIN`      | `1`                | Минимальный балл                                |
| `SCORE_MAX`      | `10`               | Максимальный балл                               |
| `DB_FILE`        | `data/db.json`     | Файл с данными                                  |
| `INIT_DATA_TTL`  | `86400`            | Срок действия данных авторизации Telegram, сек. |
| `DEV_MODE`       | —                  | `1` — локальная отладка без Telegram            |

## Локальная отладка без Telegram

```bash
DEV_MODE=1 npm start
npm run candidates -- add "Тестовый кандидат" "Разработчик"
# откройте http://localhost:3000/?c=<id>&dev=Мария
```

Параметр `dev` — имя тестового участника; меняйте его, чтобы проголосовать от разных людей.
**Не включайте `DEV_MODE` на боевом сервере.**

## Структура

```
server.js            HTTP-сервер, API, проверка подписи Telegram
store.js             хранение кандидатов и оценок (JSON-файл)
scripts/candidates.js  управление кандидатами из консоли
public/              интерфейс Mini App (HTML/CSS/JS)
```
