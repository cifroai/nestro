# Поручения — Telegram Mini App

Мини-приложение для отслеживания поручений по регламенту
«Структура и порядок поручений». Первая редакция.

Приложение — статичный веб-клиент (без сборки и бэкенда). Данные хранятся в
**Telegram CloudStorage** (синхронизируются между устройствами пользователя),
с откатом на `localStorage` при запуске в обычном браузере.

## Возможности первой редакции

- **Три категории** с фиксированным порядком вывода:
  1. Оперативные
  2. Организационно-технические
  3. Договорно-коммерческие
- **Оперативные объекты** — штатный перечень из 12 позиций в неизменяемом
  порядке; каждый объект присутствует в сводке всегда, даже без поручений
  (`Поручения отсутствуют.`).
- **Новый объект** вне перечня добавляется в конец и помечается «определить
  место» с уведомлением пользователя (Правило 4).
- **Сортировки** по регламенту:
  - орг.-технические: просрочка → ближайший срок → приоритет → без срока;
  - договорно-коммерческие: группировка контрагент → договор → срок, поручения
    с финансовым риском первыми.
- **Обязательные поля**: задача, ответственный, срок. Пустые ответственный/срок
  отображаются как `не определен` / `не установлен` — ничего не домысливается.
- **Закрытие** — только по явному подтверждению пользователя. Отметка/отчёт
  не закрывает поручение.
- **Сводка** формируется строго по шаблону регламента, копируется одной кнопкой.

## Структура проекта

```
index.html          — разметка и подключение SDK
css/styles.css      — оформление, тема от Telegram (--tg-theme-*)
js/model.js         — категории, объекты, правила сортировки и валидации
js/store.js         — хранение (CloudStorage / localStorage)
js/summary.js       — генерация сводки по шаблону
js/telegram.js      — интеграция с Telegram WebApp SDK
js/app.js           — состояние, рендеринг, формы
```

## Локальный запуск (для разработки)

```bash
# любой статический сервер, например:
python3 -m http.server 8080
# открыть http://localhost:8080
```

Вне Telegram SDK недоступен — приложение работает на `localStorage`, тема
берётся из значений по умолчанию.

## Публикация как Telegram Mini App

1. Разместить содержимое репозитория на HTTPS-хостинге (GitHub Pages, Netlify,
   Vercel и т. п.). Точка входа — `index.html`.
2. В [@BotFather](https://t.me/BotFather) создать/выбрать бота →
   `/newapp` (или `Bot Settings → Web App`).
3. Указать URL опубликованного приложения.
4. Открыть Mini App из меню бота или по прямой ссылке.

## Что не входит в первую редакцию (планы)

- Общий (командный) доступ и серверная синхронизация между пользователями.
- Разделение прав (постановщик / ответственный).
- История изменений и архив закрытых поручений.
- Уведомления о приближении срока.
- Редактирование самого регламента и порядка объектов из интерфейса.
