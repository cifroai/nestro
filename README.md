# Платформа оценки инженерного персонала бурового сервиса

Корпоративная веб-платформа дистанционного тестирования и оценки кандидатов на
инженерные должности в строительстве нефтяных и газовых скважин. Размещается на
собственном сервере Заказчика.

Платформа определяет не «психологический тип», а профессионально значимые
характеристики инженерного мышления и выдаёт **систему поддержки решения**:

```
рекомендуемая профессиональная оценка
  + доказательства (цитаты из ответов кандидата)
  + зоны риска
  + уровень уверенности
```

Кадровое решение принимает человек. Система не содержит операций «принять» и
«отказать» и не выносит психологических или медицинских суждений.

## Должности первой версии

* Инженер по буровым растворам.
* Инженер интегрированного сервиса строительства скважин.

Новая должность добавляется данными (должность, компетенции, веса, элементы и
триады Келли, кейсы, rubric) без изменения ядра системы.

## Состав оценки

| Слой | Что даёт |
|---|---|
| Репертуарная решётка Дж. Келли (адаптирована) | собственные профессиональные критерии кандидата, решётка 1–7, лестница смыслов |
| Профессиональные ситуационные кейсы | многоэтапные кейсы с последовательным раскрытием данных: решение до и после |
| Проверка аргументации | открытые вопросы о взаимосвязях и о фактическом опыте |
| Самооценка и разрыв «Я сейчас» / «Идеальный инженер» | профессиональная рефлексия |

Итоговый профиль: `Overall Professional Score 0–100` плюс восемь направлений
(техническое мышление, системное мышление, управление риском, превентивное
мышление, принятие решений, операционная зрелость, коммуникация,
профессиональная рефлексия). Каждая компетенция имеет балл, уровень 0–4,
доказательства, уровень уверенности и число подтверждающих вопросов.

## Технологический стек

* **Frontend и backend** — Next.js 15 (App Router) на TypeScript в строгом режиме;
  единственный транспорт — REST (`/api/*`), документированный OpenAPI.
* **База данных** — PostgreSQL 16, ORM Prisma, миграции только вперёд.
* **Очереди** — Redis + BullMQ (LLM-оценка, генерация PDF, обслуживание).
* **LLM** — абстракция провайдера: OpenAI, Anthropic, OpenRouter, локальная
  модель или полное отсутствие LLM (ручная оценка эксперта).
* **Отчёты** — единая печатная вёрстка для web и PDF (headless Chromium).
* **Развёртывание** — Docker Compose на Linux-сервере Заказчика.

## Быстрый старт (разработка)

```bash
cp .env.example .env          # заполнить DATABASE_URL, SESSION_SECRET, INVITATION_SECRET
npm ci
npm run db:migrate            # применить миграции
npm run db:seed               # должности, компетенции, rubric, кейсы, промпты
npm run admin:create -- --email admin@example.com   # пароль печатается один раз
npm run dev                   # http://localhost:3000
npm run worker                # в отдельном терминале: очереди оценки и отчётов
```

Платформа работоспособна без LLM (`LLM_PROVIDER=none`): сессии сохраняются,
статус оценки остаётся `PENDING`, эксперт может выставить оценки вручную.

## Развёртывание

```bash
cp .env.example .env          # заполнить секреты: openssl rand -base64 48
docker compose --profile prod up -d --build
docker compose exec app npx prisma migrate deploy
docker compose exec app npx tsx prisma/seed/index.ts
docker compose exec app npx tsx scripts/createAdmin.ts --email admin@example.com
curl -fsS https://<host>/api/readyz
```

Подробно — [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md), включая резервное
копирование (`ops/scripts/backup.sh`), восстановление (`ops/scripts/restore.sh`)
и план аварийного восстановления.

## Роли

| Роль | Назначение |
|---|---|
| SuperAdmin | полный доступ, управление пользователями и правами |
| AssessmentAdmin | конструктор ассессментов, веса, rubric, пороги, промпты, публикация версий |
| HR | приглашения, дашборд, отчёты, сравнение, экспорт |
| TechnicalExpert | экспертная проверка оценок, комментарии, маркеры риска |
| Viewer | чтение отчётов и аналитики без изменений и без выгрузки персональных данных |
| Candidate | прохождение теста по одноразовой ссылке, без учётной записи |

## Методические принципы

1. Итоговая оценка не формируется одним запросом к модели: агрегацию выполняет
   детерминированный код, проверяемый unit-тестами.
2. Каждый автоматический вывод обязан ссылаться на дословную цитату из ответа
   кандидата; балл без подтверждённой цитаты снимается.
3. Отсутствие доказательств — это `NOT_ENOUGH_EVIDENCE`, а не ноль.
4. Уровень уверенности отделён от балла и не является оценкой квалификации.
5. Критические компетенции (hard-gates) не отклоняют кандидата автоматически —
   они требуют дополнительной проверки.
6. Опубликованная версия ассессмента неизменяема; исторические результаты
   не пересчитываются молча.
7. Возраст, пол, национальность, вероисповедание, политические убеждения,
   данные здоровья и семейное положение не собираются и в оценке не участвуют.
