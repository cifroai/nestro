# Оценка кандидата — на Telegram Serverless

Та же Mini App для оценки кандидатов, но **без своего сервера**: бот, база данных и страница
приложения работают на инфраструктуре Telegram
([Telegram Serverless](https://core.telegram.org/bots/serverless)).

## Что умеет

**Участник оценки** (переходит по ссылке из Express):
- видит карточку кандидата, открывает резюме;
- ставит балл 1–10, пишет комментарий, нажимает **Принять / Отклонить / В резерв**;
- после голосования видит **общую оценку**: средний балл, распределение решений,
  решение большинства и оценки всех участников; может изменить свою оценку.

**Рекрутер** (в чате с ботом):

| Команда | Что делает |
|---|---|
| `/new Иванов Иван; Ведущий аналитик` | добавляет кандидата и присылает ссылку для Express |
| `/list` | все кандидаты, число оценок, ссылки |
| `/results <код>` | итоги оценки |
| документ с подписью `/resume <код>` | прикрепляет резюме (до 20 МБ) |
| `/delete <код>` | удаляет кандидата и его оценки |
| `/myid` | показывает ваш Telegram ID |

### Как работает резюме

Файлы хранятся в самом Telegram. Загрузить резюме можно в приложении (кнопка «Загрузить
резюме», до 10 МБ) или прислать боту документом с подписью `/resume <код>`.
Кнопка **«Открыть резюме»** присылает файл участнику в личный чат с ботом — Telegram
открывает PDF, Word и картинки встроенным просмотрщиком. При первом нажатии Telegram
спросит разрешение на сообщения от бота.

## Установка

Нужен компьютер с [Node.js 18+](https://nodejs.org) — только для публикации, после неё
компьютер можно выключить.

### 1. Включите Serverless у бота

В @BotFather: откройте `@nestro_hr_bot` → **Serverless** → включите.
Затем **CLI Access → Access token** — скопируйте токен (это отдельный токен, не тот,
что выдавался при создании бота).

### 2. Опубликуйте приложение

```bash
git clone -b claude/brave-johnson-k6q0sj https://github.com/cifroai/nestro.git
cd nestro/interview-rating-serverless
npm install
npm run setup          # подготовит проект и спросит CLI-токен из шага 1
npm run deploy         # загрузит бота и страницу приложения
npm run migrate        # создаст таблицы в базе (подтвердите — y)
```

`npm run deploy` напечатает адрес приложения вида `https://app123456.tgcloud.ai/`.

### 3. Создайте Mini App в @BotFather

`/newapp` → `@nestro_hr_bot` → название «Оценка кандидата», описание, картинка 640×360 →
**URL** из предыдущего шага → **short name** `rate`.

Если выберете другой short name — поменяйте `APP_SHORT_NAME` в `tgcloud/lib/config.js`
и выполните `npm run deploy`.

### 4. Ограничьте доступ к управлению (рекомендуется)

По умолчанию добавлять кандидатов может любой, кто напишет боту. Чтобы оставить это только
рекрутерам:

1. Каждый рекрутер отправляет боту `/myid`.
2. Впишите ID в `ADMIN_IDS` в `tgcloud/lib/config.js`, например `[123456789, 987654321]`.
   Аналогично `RESUME_UPLOADER_IDS` — кто может загружать резюме (пусто — любой участник).
3. `npm run deploy`.

### 5. Пользуйтесь

Напишите боту `/new Иванов Иван; Ведущий аналитик` — он пришлёт ссылку
`https://t.me/nestro_hr_bot/rate?startapp=…`. Разместите её в Express.

## Настройки

Все настройки — в `tgcloud/lib/config.js` (после правки — `npm run deploy`):
шкала оценки (`SCORE_MIN`/`SCORE_MAX`), список рекрутеров, допустимые форматы и размер резюме,
названия решений.

## Обновление

```bash
git pull
npm run deploy
npm run migrate        # только если менялась tgcloud/schema.js
```

## Разработка

```
tgcloud/schema.js          таблицы: candidates, votes
tgcloud/lib/config.js      настройки
tgcloud/lib/rating.js      общая логика
tgcloud/handlers/message.js  команды бота
tgcloud/endpoints/         функции, которые вызывает Mini App
public/                    интерфейс Mini App
test/                      локальные тесты на заглушках SDK
```

`npm test` — проверка логики без публикации (Node.js 22+).
Проверить функцию прямо на платформе без публикации:
`npx tgcloud run endpoints/getCandidate '{ id: "код" }' --ctx '{ initData: { user: { id: 1 } } }'`.

## Важно

- Данные (оценки, резюме) хранятся на серверах Telegram. Резюме — персональные данные
  кандидатов; согласуйте такой способ хранения со службой безопасности/юристом компании.
- Serverless — новая функция Telegram (октябрь 2026); у некоторых ботов доступ к ней
  выдаётся по запросу через @BotFather.
